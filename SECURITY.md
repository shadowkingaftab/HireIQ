# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities to security@proofhire.io.

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will acknowledge receipt within 24 hours and provide a detailed response within 72 hours.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Security Updates

Security updates will be released as patch versions. We recommend always running the latest patch version.

## Disclosure Policy

- We follow coordinated disclosure
- We will not publicly disclose the vulnerability until a fix is available
- We will credit reporters who follow this policy
