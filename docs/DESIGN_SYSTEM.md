# Design System

## Tokens

### Colors
- `primary`: #2563eb
- `success`: #16a34a
- `danger`: #dc2626
- `warning`: #f59e0b
- `muted`: #64748b

### Typography
- Sans: system UI font stack
- Mono: monospace stack
- Scale: xs (12px) through 2xl (24px)

### Spacing
- 8px base grid
- xs through xl presets

## Motion

- Duration: 200ms default
- Easing: ease-in-out
- Fade-in animation for view transitions

## Accessibility

- Focus ring: 3px blue ring
- Screen-reader-only utility
- Semantic HTML and ARIA labels

## Components

UI primitives in `src/components/ui/`:
- Button, Badge, Dialog, Drawer, Dropdown
- Tooltip, Tabs, Progress, Skeleton, Toast, EmptyState
