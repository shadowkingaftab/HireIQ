# Privacy

## Data Minimization

Only necessary candidate data is collected and retained.

## Consent

- Explicit consent for evidence ingestion
- Purpose-limited data processing
- Revocable at any time

## Retention

Automated cleanup jobs enforce retention policies:
- Stale sessions removed
- Expired invitations purged
- Evidence aged out per policy

## Right to Deletion

Candidates can request data deletion via:
- Account deletion
- Specific evidence removal
- Organization-level GDPR requests

## Encryption

- Data encrypted at rest
- Secrets encrypted in transit
- Backups encrypted

## Access Control

- Role-based data access
- Tenant isolation
- Audit trail for all access
