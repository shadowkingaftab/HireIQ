# Incident Response

## Severity Levels

- P0: Active data breach or system compromise
- P1: Service down or major functionality impaired
- P2: Degraded service or security vulnerability
- P3: Minor issue or potential risk

## Response Procedure

### P0/P1
1. Identify and contain
2. Notify on-call team
3. Begin investigation
4. Communicate status to stakeholders
5. Resolve and verify
6. Post-mortem within 48 hours

### P2
1. Triage and assign owner
2. Fix within SLA
3. Document resolution

### P3
1. Schedule fix
2. Document in backlog

## Escalation

If unresolved after 1 hour, escalate to engineering lead.
If data breach suspected, notify legal and DPO within 72 hours.
